# Changelog

## [0.0.3] - 2025-12-06
### Added
- **Dynamic Colors:** The CPU bar now changes color automatically based on the average load (Green, Yellow, Orange, Red).
- **Color Toggle:** Added an option in the quick-pick menu to easily enable/disable the color feature.

## [0.0.2] - 2025-12-06
### Added
- Refresh rate selection added to the status bar click menu (500ms, 1000ms, 2000ms).
- Initial support for high-resolution Braille characters.
