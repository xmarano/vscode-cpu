## Features

* **Visual Graph:** Uses Braille characters (like `⡀`, `⣀`, `⣄`, `⣿`) to visualize load intensity.
* **Per-Core Tracking:** Shows individual usage for every CPU core.
* **Interactive:** Click the status bar item to change the update frequency.

## Configuration

Simply **click on the CPU text** in the status bar to toggle the refresh rate:
* `500ms` (Fast)
* `1000ms` (Normal)
* `2000ms` (Slow)
